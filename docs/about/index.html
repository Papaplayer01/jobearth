JoBearth

A live site that collects fresher and internship posts across India, removes duplicates, tags each post by role and city, and refreshes itself every day.

01 Architecture

One daily GitHub Action, five steps, no server.

01

Collect

Adzuna, company career boards, Remotive and RemoteOK feeds.

02

Filter

India and fresher posts only. Scam-looking ads are dropped.

03

Dedupe

The same job from two sources becomes one card.

04

Tag

An LLM gives each post a role and a city, 20 posts per request. Cached per post. Keyword rules are the fallback.

05

Publish

Static pages, role and city pages, a sitemap and a feed, served by GitHub Pages.

Fifteen roles: Cloud, DevOps, Backend, Frontend, Full-stack, QA & Automation, Data, ML & AI, Mobile, Security, Support, Design, Sales & Marketing, Operations & HR, Other. Every tag records which tagger made it, so accuracy can be measured separately.

Saw

Role from title first, better city parsing, LLM tagging

Details popup felt empty

04 Run it yourself

Fork, add a key, run.

  1. Fork the repo and enable GitHub Pages from main and /docs.
  2. Create a free key at aistudio.google.com, then save it and choose the model: 
    gh secret set GEMINI_API_KEY
gh variable set TAG_MODEL --body "gemini-3.5-flash-lite"
  3. Add ADZUNA_APP_ID and ADZUNA_APP_KEY (free at developer.adzuna.com). Other keys are optional.
  4. Run the “Find working job boards” workflow once, then the daily one: 
    gh workflow run "Daily refresh"
  5. Check the log for the usage line. Tokens above zero mean the LLM is tagging: 
    gh run view --log | grep "LLM usage"

To repeat the accuracy check: python3 evaluation/eval_sample.py make, then evaluation/review.py to correct the tags, then eval_sample.py score.

05 Limits

What to keep in mind.

Posts are short snippets from the sources, and each card links to the original. Fresher detection is keyword based, so some senior posts slip through. Free-tier limits and model names change often, so check the “LLM HTTP” line in the log if tagging stops. Tools used: Gemini for tagging at run time, and Claude in chat for building and debugging.
